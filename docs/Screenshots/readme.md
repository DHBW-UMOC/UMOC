# Überblick über Screenshots
Dieser Ordner enthält Bilder der wichtigsten Anzeigen und Funktionen unseres Messengers.

Zuerst gelangen Sie auf die Anmeldeseite. Dort können Sie sich entweder anmelden oder auf „Registrieren“ klicken, um einen neuen Benutzer zu erstellen.

Nach erfolgreicher Anmeldung oder Registrierung werden Sie zur Hauptseite weitergeleitet. Dort können Sie neue Kontakte suchen und einen Chat auswählen, um diesen zu öffnen.

Der Chat ist voll funktionsfähig und unterstütz gängige Funktionen wie senden und löschen von Text und Emojis. Darüber hinaus werden Nachrichten sofort beim Empfänger angezeigt ohne sie absenden zu müssen.

Wenn Sie auf den Namen des Chats klicken, öffnen Sie die Informationsseite des Kontakts oder der Gruppe.

Auf der linken Seite, oberhalb der aufgelisteten Chats, befindet sich eine Suchzeile. Dort können Sie nach Benutzern suchen. Zuerst werden Ihnen bereits bekannte Nutzer angezeigt, danach solche, mit denen Sie noch nicht geschrieben haben.

Unten links können Sie auf Ihr eigenes Profil klicken, um es zu bearbeiten oder sich abzumelden.

Daneben befindet sich der UMOC Shop wo mit en aquirierten Punkten UMOC Items gekauft werden können, welche in einem Chat angewandt werden können.

Darüber hinaus haben wir viele weitere kleinere Funktionen eingebaut, die Sie gerne selbst entdecken dürfen.
